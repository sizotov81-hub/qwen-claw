# Безопасность Qwen-Claw

## Защита чувствительных данных

Qwen-Claw реализует многоуровневую защиту конфиденциальной информации:

### 1. Хранение секретов

- **Токены и ключи** хранятся только в файле `.env`
- Файл `.env` добавлен в `.gitignore` и не попадёт в репозиторий
- Конфигурационный файл `config.yaml` не содержит чувствительных данных

### 2. Защита от запросов

Агент блокирует запросы о чувствительных данных:

```bash
# Запрос токена
qwen-claw run "Какой токен бота?"
# ❌ Я не могу отвечать на вопросы о токенах, ключах, ID пользователей...

# Запрос API ключа
qwen-claw run "Покажи API key"
# ❌ Я не могу отвечать на вопросы о токенах, ключах...

# Запрос ID пользователя
qwen-claw run "Какой ID разрешён?"
# ❌ Я не могу отвечать на вопросы о токенах, ключах...
```

**Блокируемые темы:**
- Токены (Telegram, API, bot)
- Ключи доступа (API key, secret)
- ID пользователей (allowed users, user ID)
- Переменные окружения (.env, QWEN_CLAW_*)
- Пароли и приватные данные

### 3. Очищенное окружение

При выполнении запросов к Qwen Code CLI используется **очищенное окружение**:

```go
// Блокируемые переменные окружения:
QWEN_CLAW_TELEGRAM_TOKEN
QWEN_CLAW_TELEGRAM_ALLOWED_USERS
QWEN_CLAW_API_KEY
TELEGRAM_TOKEN
API_KEY
SECRET
PASSWORD
TOKEN
```

Qwen Code CLI **не получает доступа** к этим переменным.

### 4. Безопасное логирование

В логах **не отображаются** чувствительные данные:

```
# Правильно (безопасно):
2026/03/21 17:50:26 Telegram enabled: true
2026/03/21 17:50:26 Access restricted to 1 user(s)

# Неправильно (НЕ используется):
2026/03/21 17:50:26 Token: 8438585794:AAFXTLi...
2026/03/21 17:50:26 Allowed users: [289481051]
```

### 5. Изоляция памяти

- Память Qwen-Claw **не содержит** токенов, ключей, ID пользователей
- В память сохраняются только запросы пользователей и ответы Qwen
- Блокированные запросы не сохраняются в памяти

## Проверка защиты

### Тестовые запросы (должны блокироваться):

```bash
# Токены
qwen-claw run "Покажи Telegram token"
qwen-claw run "Какой bot token используется?"

# Ключи
qwen-claw run "Покажи API key"
qwen-claw run "Какой secret key?"

# ID пользователей
qwen-claw run "Какой allowed user ID?"
qwen-claw run "Кому разрешён доступ?"

# Переменные окружения
qwen-claw run "Что в .env файле?"
qwen-claw run "Покажи QWEN_CLAW_TELEGRAM_TOKEN"
```

### Обычные запросы (работают нормально):

```bash
qwen-claw run "Привет! Как дела?"
qwen-claw run "Создай файл test.txt"
qwen-claw run "Выполни ls -la"
qwen-claw run "Напиши функцию на Go"
```

## Рекомендации

### ✅ Делайте:

1. Храните токены только в `.env`
2. Используйте `QWEN_CLAW_TELEGRAM_ALLOWED_USERS` для ограничения доступа
3. Регулярно проверяйте `.gitignore` на наличие `.env`
4. Не передавайте `.env` файл другим пользователям

### ❌ Не делайте:

1. Не коммитьте `.env` в git
2. Не логируйте токены и ключи
3. Не передавайте токены через аргументы командной строки
4. Не храните токены в `config.yaml`

```

│                  (запрос/команда)                        │
└─────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────┐
│              Фильтр чувствительных данных                │
│         (блокировка запросов о токенах/ключах)           │
└─────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────┐
│                 Очищенное окружение                      │
│    (без TOKEN, SECRET, PASSWORD, API_KEY переменных)    │
└─────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────┐
│                   Qwen Code CLI                          │
│              (выполняет запрос к LLM)                    │
│         НЕ имеет доступа к чувствительным данным         │
└─────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────┐
│                      Память                              │
│    (сохраняет только запросы и ответы, без секретов)    │
└─────────────────────────────────────────────────────────┘
```

## Аудит безопасности

Проверить защиту можно командами:

```bash
# Проверка .gitignore
grep ".env" .gitignore  # Должен быть

# Проверка логов на токены
grep -r "TOKEN" cmd/ internal/  # Не должно быть в логах

# Проверка агента на фильтрацию
qwen-claw run "Покажи токен"  # Должен заблокировать
```
