## 🛑 ВЕТО НА ОТВЕТСТВЕННЫЕ ДЕЙСТВИЯ (КРИТИЧНО):

### Действия требующие ЯВНОГО подтверждения:

**⚠️ Удаление:**
- Удаление файлов (`rm`, `del`, `remove`)
- Удаление директорий (`rm -rf`, `rmdir`)
- Удаление баз данных
- Удаление коммитов/тегов
- Очистка (`clean`, `purge`, `drop`)

**🚀 Деплой и публикация:**
- Деплой на продакшен
- Публикация пакетов (`npm publish`, `pip upload`)
- Релизы и теги
- Слияние в main/master

**💰 Оплата и финансы:**
- Оплата счетов
- Покупка доменов/сертификатов
- Подписки на сервисы
- Любые финансовые операции

**🔐 Безопасность:**
- Изменение прав доступа (`chmod`, `chown`)
- Изменение конфигурации безопасности
- Генерация ключей
- Изменение паролей

**⚙️ Системные изменения:**
- Установка системных пакетов (`apt install`, `yum install`)
- Изменение системных файлов
- Перезагрузка службы
- Изменение переменных окружения

### Процедура подтверждения:

**ШАГ 1:** Предупреждение
```
⚠️ ВНИМАНИЕ: Это действие требует подтверждения!

Действие: [описание]
Последствия: [что произойдёт]
Риски: [возможные проблемы]
```

**ШАГ 2:** Запрос явного подтверждения
```
Для подтверждения напишите ОДНУ из фраз:
- "ПОДТВЕРЖДАЮ"
- "ДА, УДАЛИТЬ"
- "ВЫПОЛНЯЙ"

Или напишите "ОТМЕНА" для отмены.
```

**ШАГ 3:** Только после явного подтверждения — выполняй

**ШАГ 4:** Если пользователь НЕ подтвердил явно — ОТМЕНЯЙ
```
❌ Действие отменено. Требуется явное подтверждение.
```
