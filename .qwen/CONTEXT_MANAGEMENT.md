# 🧠 Система управления контекстом Qwen-Claw

## 📋 Описание

Система управления контекстом предотвращает переполнение контекстного окна LLM, обеспечивает своевременное сжатие данных и автоматическое переключение сессий для избежания галлюцинаций и потери данных.

---

## 🎯 Возможности

### 1. **Мониторинг использования контекста**
- Отслеживание количества токенов в реальном времени
- 4 уровня статуса: Normal → Warning → Critical → Overflow
- Визуальные предупреждения в логах

### 2. **Автоматические предупреждения**

| Статус | Заполнение | Действие |
|--------|------------|----------|
| 🟢 Normal | < 50% | Нет действий |
| 🟡 Warning | 50-75% | Предупреждение в логе |
| 🟠 Critical | 75-90% | Рекомендация сжатия |
| 🔴 Overflow | > 90% | Автоматическое сжатие/новая сессия |

### 3. **Сжатие контекста**
- Удаление старых токенов с низким приоритетом
- Сохранение важных сообщений (приоритет ≥ 8)
- Сохранение незавершённых задач

### 4. **Умное переключение сессий**
- Автоматическое создание новой сессии при переполнении
- Перенос незавершённых задач в новую сессию
- Очистка завершённых задач

### 5. **Проверка необходимости контекста**
- Изоляция контекста по задачам (TaskID)
- Очистка контекста завершённых задач
- Запуск новых задач в чистой сессии

## 🔧 Использование

### Проверка статуса контекста

```bash
# В интерактивном режиме
/context status
```

**Вывод:**
```
📊 Context Usage:
  Current: 4500 tokens
  Max:     8000 tokens
  Usage:   56.2%
  Status:  ⚠️ WARNING

💡 Recommendation: Consider compressing context
```

### Сжатие контекста

```bash
# Ручное сжатие
/context compress
```

**Что делает:**
- Удаляет старые сообщения с низким приоритетом
- Объединяет последовательные сообщения
- Сохраняет важные токены

### Новая сессия

```bash
# Начать новую сессию
/session new
```

**Что делает:**
- Создаёт новую сессию в `.qwen/local/session-<timestamp>.json`
- Переносит незавершённые задачи
- Очищает контекст

### Просмотр использования

```bash
# Детальная статистика
/context usage
```

**Вывод:**
```
📊 Context Usage:
  Current Tokens:   4500
  Max Tokens:       8000
  Usage Percent:    56.2%
  Status:           warning
  Token Count:      45
  Available:        3500

📋 Recent Messages:
  👤 User: Привет
  🤖 Assistant: Здравствуйте!
  ...
```

## ⚙️ Конфигурация

### Настройки по умолчанию

```go
ContextConfig{
    MaxTokens:          8000,     // Лимит токенов
    WarningThreshold:   0.5,      // 50%
    CriticalThreshold:  0.75,     // 75%
    OverflowThreshold:  0.9,      // 90%
    AutoCompress:       true,     // Автосжатие
    AutoNewSession:     true,     // Автоновая сессия
    PreserveIncomplete: true,     // Сохранять незавершённые
}
```

### Изменение настроек

```bash
# Установить лимит токенов
/context config --max-tokens 16000

# Изменить порог предупреждения
/context config --warning-threshold 0.6

# Включить/отключить автосжатие
/context config --auto-compress true
```

## 📁 Структура данных

### ContextToken

```go
type ContextToken struct {
    Content      string    // Содержимое
    Type         string    // user/assistant/system
    Tokens       int       // Количество токенов
    Timestamp    time.Time // Время создания
    Priority     int       // 0-10 (10 = важный)
    TaskID       string    // ID задачи
    IsIncomplete bool      // Незавершённая задача
}
```

### Приоритеты

| Приоритет | Тип | Описание |
|-----------|-----|----------|
| 10 | System | Системные промпты |
| 8-9 | Critical | Критические инструкции |
| 5-7 | Normal | Обычные сообщения |
| 0-4 | Low | Временные/не важные |

## 🎯 Стратегии оптимизации

### 1. **При Warning (50-75%)**
- ✅ Продолжать работу
- ⚠️ Готовиться к сжатию
- 💡 Предложить пользователю завершить текущие задачи

### 2. **При Critical (75-90%)**
- ⚠️ Предложить сжатие
- 🗑️ Удалять старые низкоприоритетные токены
- 💬 Предложить начать новую сессию

### 3. **При Overflow (>90%)**
- 🚨 Автоматическое сжатие
- 🔄 Создание новой сессии
- 📦 Перенос незавершённых задач

## 🛡️ Безопасность

### Защита от галлюцинаций

1. **Изоляция задач** — каждая задача имеет свой TaskID
2. **Очистка завершённых** — удалённые задачи не влияют на новые
3. **Приоритизация** — важные сообщения сохраняются
4. **Временные метки** — старые сообщения удаляются первыми

### Защита от потери данных

1. **Сохранение незавершённых** — IsIncomplete=true защищает от удаления
2. **Перенос в новую сессию** — контекст не теряется
3. **Персистентность** — все данные в `.qwen/local/`

## 📈 Метрики

### Отслеживаемые метрики

- `current_tokens` — текущее количество токенов
- `max_tokens` — максимальный лимит

- `available_tokens` — доступно токенов

## 🎯 Best Practices

### ✅ ДЕЛАЙТЕ:

1. **Мониторьте контекст** — регулярно проверяйте `/context status`
2. **Сжимайте вовремя** — при 70-80% заполнения
3. **Завершайте задачи** — очищайте контекст завершённых задач
4. **Используйте TaskID** — для изоляции контекста задач

### ❌ НЕ ДЕЛАЙТЕ:

1. **Игнорируйте предупреждения** — это приведёт к переполнению
2. **Храните всё в контексте** — сжимайте старые данные
3. **Забывайте завершать задачи** — ClearTaskContext после завершения
